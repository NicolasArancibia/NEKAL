# Nekal — exploración del espacio de trabajo

**8 de octubre de 2026 · Investigación, sin código ni cambios en la app**

Se prepararon cuatro estilos de escritorio y un recorrido móvil con datos ficticios. Todos parten del modelo real: **Espacio → Grupo opcional → Ítem**. El mismo escenario tiene 3 espacios, 4 grupos y 16 actividades de los ocho tipos de Nekal.

**Recomendación provisional:** Territorios para organizar y leer; Red para explorar dependencias. Islas es una alternativa visual con profundidad aparente; Universo 3D es un modo de exploración a validar.

## Alcance y revisión

No se generó código, no se instalaron dependencias ni se modificó la aplicación o sus datos. Se leyó el proyecto local y se navegó el referente Nico Borja. El acceso de inspección a la pestaña de Nekal falló; el informe distingue esa limitación.

Las cinco imágenes son maquetas raster realizadas con ImageGen integrado. Se revisaron conteos, pertenencia y sentido de flechas, incluyendo una segunda revisión independiente. No hay pruebas con usuarios ni resultados de rendimiento. La iconografía, lectura inclinada, solapamientos 3D y adaptación precisa a tamaños de pantalla siguen siendo decisiones de diseño.
